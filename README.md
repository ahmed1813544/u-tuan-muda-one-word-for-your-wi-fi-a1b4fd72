## The word

**Ghosting**

Home Wi-Fi ghosts you — it vanishes mid-call, mid-download, with no
explanation, exactly like a bad date. Funny at once, true to how home
Wi-Fi actually behaves, and it works as a network name with no context
needed.

## How it works

`main.py` (Python 3.13, standard library only) writes the word to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`). The output is a single word, 8 characters, no trailing
newline, and byte-identical on every run.

```sh
python3 main.py
```
